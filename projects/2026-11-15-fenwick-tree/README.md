# Fenwick Tree Range-Sum Engine

Efficient mutable prefix sums, point updates and inclusive range queries with logarithmic operations.

## Usage

Python 3.9+; Python standard library only.

```sh
cd projects/2026-11-15-fenwick-tree
python tool.py
python -m unittest -v test_tool.py
```

## Design

Efficient mutable prefix sums, point updates and inclusive range queries with logarithmic operations. Designed as an educational, dependency-free implementation with deterministic unit tests and explicit input checks.

## Limitations

Small-scale demonstration, not a production service. Review concurrency, security, performance, and input limits before deployment.
