# Disk Seek Scheduling Simulator

FCFS, SSTF and SCAN scheduling with total head movement, ordering and bounds validation.

## Usage

Python 3.9+; Python standard library only.

```sh
cd projects/2026-11-15-disk-scheduling
python tool.py
python -m unittest -v test_tool.py
```

## Design

FCFS, SSTF and SCAN scheduling with total head movement, ordering and bounds validation. Designed as an educational, dependency-free implementation with deterministic unit tests and explicit input checks.

## Limitations

Small-scale demonstration, not a production service. Review concurrency, security, performance, and input limits before deployment.
