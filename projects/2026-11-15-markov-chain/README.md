# Markov Chain Distribution Simulator

Finite-state transition matrices, probability validation, distribution evolution and convergence estimates.

## Usage

Python 3.9+; Python standard library only.

```sh
cd projects/2026-11-15-markov-chain
python tool.py
python -m unittest -v test_tool.py
```

## Design

Finite-state transition matrices, probability validation, distribution evolution and convergence estimates. Designed as an educational, dependency-free implementation with deterministic unit tests and explicit input checks.

## Limitations

Small-scale demonstration, not a production service. Review concurrency, security, performance, and input limits before deployment.
